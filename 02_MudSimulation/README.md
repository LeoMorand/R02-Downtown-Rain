# 实时泥浆模拟（Niagara Grid2D）

泥浆模拟 Shader、运行时与编辑器插件，以及研究和验证脚本。

关键文件：`Shaders/`、`Plugins/MudRuntime/`、`Plugins/MudAuthoring/`、`Plugins/MudShaderLab/`、`Tools/`、`Docs/CURRENT_PROFESSIONAL.md`。

泥浆：流动细节 GPU 增量约 0.1 ms（RTX 4060 Laptop，1280×720，D3D12 SM6，8 轮对照）。

演示视频：待补 B 站链接
