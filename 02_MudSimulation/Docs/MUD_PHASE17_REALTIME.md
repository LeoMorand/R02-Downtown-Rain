# Phase17：全功能实时录制

视频：`Deliverables/MudFullFeatures_20261030/Mud_FullFeatures_Runtime_1080p30.mp4`。

4分09秒，1920×1080，30 fps，无音轨。只裁掉准备时间，没有片头、章节标题、后期字幕、技术图卡或变速。左侧中文读数来自实时组件参数，右侧为 UE 原生 `stat fps` / `stat unit`，显示帧率、Frame / Game / Draw / RHI / GPU 时间、内存、显存、渲染分辨率、draw call 和图元数。

录制内容：

- 薄层行走、转向、停止、跳跃；深池进入与退出。
- 浅色、深色、亮度、粗糙度、细节强度和密度。
- 0 / 20 / 40 cm 表面起伏，以及 5 / 50 / 90 cm 池深预设。
- 黏稠感 0 / 1、行走阻力开关与实际移动倍率。
- 薄层细节流动开关与速度、深池细节流动倍率。
- 完整平面、圆角矩形、椭圆、不规则泥潭；宽高、偏移、旋转、圆角、不规则程度与种子。
- 薄湿、厚重、恢复默认预设。
- 512 / 1024 / 2048 输出与法线分辨率，及重建后的交互恢复。
- 两块泥浆独立调色和双区总览。

实现：`mud_realtime_demo.py` 通过 PIE 帧回调、Enhanced Input 和 CharacterMovement 驱动角色，用真实游戏相机展示效果。参数由脚本定时触发并读回；没有录制鼠标拖动 Details 面板。`record_realtime_window.py` 通过 Windows Graphics Capture 仅采集 UE 浮动窗口；即使窗口被其他应用遮挡，也不会改为采集桌面。`finalize_realtime_demo.py` 按单调时钟标记裁掉片头尾准备时间，保留原速，检查覆盖范围并完整解码视频。

运行记录：`Verification/MudProfessional/phase17-runtime/take03/`。take01 为机位预检，take02 为预设调用排查，均不作为最终成片。take03 完整结束、无脚本错误，覆盖18段。没有启用 t.OverrideFPS 或引擎固定帧率；实际游戏帧率以原生读数为准。30 fps 仅为视频采样率。

范围：性能是当前研究编辑器内双区场景在采集负载下的原生读数，不能作为单独泥浆求解器成本或 Shipping 性能。视口1920×1084、100%渲染，中心裁切至1920×1080。原生 RenderRes 长行在右侧有少量裁切，其余核心读数保留。黏稠感为艺术参数；区域只裁切可见表面；显示质量控制输出和法线 RT，内部主网格仍为2048。

结束后已退出 PIE，恢复浮动窗口前的尺寸、位置、普通 Play 模式、屏幕比例和 Slate 设置。没有保存或新增 UE 资产，173个历史工程文件哈希均未变化，脏包为0。工程仍在 Phase15 双区地图。完整视频检查结果、参数采样和校验和见投递目录。
